Features

できることWhat it can do

シンプルだけど、かゆいところに手が届く。 Simple, with the details that matter.

全タブのURLをコピーCopy all tab URLs

今のウィンドウのタブをすべて、ワンクリックで。Every tab in the current window, in one click.

選んだタブだけコピーCopy selected tabs

Ctrl / ⌘ + クリックで選んだタブのURLだけを。Select tabs with Ctrl / ⌘ + click, then copy only those.

カスタムボタンCustom buttons

表示中のページから、条件に合うリンクだけを集めてコピー。記事一覧から記事URLだけ、などに。Collect only the links on the current page that match a hostname and path pattern — e.g. every article on a list page.

エクスポート / インポートExport / Import

カスタムボタンを JSON で書き出して、別のブラウザへ持ち運べます。Move your custom buttons between browsers as JSON.

日本語 / EnglishEnglish / 日本語

ポップアップの歯車から、表示言語をいつでも切り替え。Switch the UI language anytime from the popup's settings.

外部送信なしLocal only

リンクの収集はブラウザの中だけで完結。どこにも送信しません。Links are collected in your browser. Nothing is sent anywhere.

Get started

使い方は3ステップThree steps

覚えることはほとんどありません。There's almost nothing to learn.

アイコンをクリックClick the icon

ツールバーのアイコンからポップアップを開きます。Open the popup from the toolbar.

ボタンを押すPress a button

「全タブ」「選択中のタブ」、またはカスタムボタンを選びます。All tabs, selected tabs, or one of your custom buttons.

貼り付けるPaste

メモ、チャット、スプレッドシート……どこへでも。Notes, chat, spreadsheets — anywhere.

Custom buttons

ページ内の「欲しいリンクだけ」を集めるGrab just the links you want from a page

ホスト名とパスの正規表現を決めておくと、表示中のページからそれに合うリンクだけを抜き出してコピーします。初期状態で Qiita の記事リンク用ボタンが入っています。 Set a hostname and an optional path regex, and the button pulls only the matching links from the page you're viewing. A button for Qiita article links is included out of the box.

  • 重複したリンクは自動で除外Duplicate links are removed
  • URLを貼ればホスト名だけを自動で取り出しPaste a URL and the hostname is extracted for you
  • 英語用の表示名も別に設定可能Set a separate English display name
